# ARS Change history POC

POC prototype for the ARS **Change History** feature — a "History" tab on the User Detail page that shows a grouped, expandable timeline of operations performed on a user, with a details side panel for drilling into a single operation.

Generated by [Up-Skill](https://github.com/slowpulsestudio/iris-proto-build-react) — an AI prototyping skills library. This project's AI instructions are assembled from the skills below into `master-skills.md`. To pull in the latest skill updates, run `/skill-me-up` again.

**Figma file:** https://www.figma.com/design/CrYylB0Tp9GJjNKiOBUryf/ARS_WebUI2_Change_History?node-id=1012-2258&t=bSvZVdaRNepbOL2z-1

## What this prototype is testing

The Figma file is an exploration page with many design variants. The four frames this prototype is built from (left to right on the page) represent one flow:

| Frame | What it shows |
|---|---|
| `Compact-Timeline` | Default state: operations grouped by date, each group collapsed to a header row (date + operation count) with a connecting timeline line |
| `Compact-Timeline-Expanded v2` | A date group expanded to reveal its individual operation rows |
| `Compact-Timeline-Expanded-Hover` | Hover affordance on an individual operation row |
| `Details Sidesheet` | Clicking an operation row opens a right-docked side panel with the operation summary, a before/after "Properties Changed" table, and secondary operation details |

All four live under the **History → Change History** tab of the existing User Detail page (`#/users/:id`) — this is *not* a new top-level nav item. A **User Activity** sub-tab exists alongside Change History but is out of scope for this pass (left as a placeholder).


## Getting started

The app lives in `src/iris-shell/` (this is also the Vercel **Root Directory** setting).

```bash
cd src/iris-shell
pnpm install
pnpm dev      # local dev server
pnpm build    # production build
```
